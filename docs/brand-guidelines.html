00 Essence what we are

Right Agent — a sandboxed multi-agent runtime for Claude Code, built on NVIDIA OpenShell. Each agent runs as its own Claude Code session inside its own OpenShell sandbox with a declarative YAML policy. A Rust CLI orchestrates lifecycles via process-compose.

The brand looks into deep space through a precise instrument. Mood: research, mystery, efficiency. Warm-but-cool — a deep jewel palette: warm-neutral plum base, cool teal action, ruby identity, gold warmth.

double meaning

right = proper (security-first, sandboxed by default)
right = the one that fits (the right agent for the job)

heritage mark

The claw is a visual signature inherited from the project's original name.
Read it as a metaphor for grip: the runtime holds agents inside their sandboxes — a tracked object in the field.

Core promise. Run multiple autonomous Claude Code agents safely — each in its own sandbox, with its own identity and memory, with a single command.

Emotional payoff. Confidence. "I can leave them running."

Naming. In prose — Right Agent (Title Case, two words). In wordmark — right agent (lowercase). In CLI — rightagent (one token, no space, no hyphen).

01 Logo system three marks, one family

The brand has three marks: primary (strict, functional), character (friendly, for stage), wordmark (anywhere text is needed). They don't compete — they cover different sizes and registers. The mark is always rendered in ruby — the identity color.

1.1 Primary mark

Primary on deep-fieldRuby claw + white check on #121016. Primary context — dev tools, terminals, dark UI.
Primary on lightRuby claw on pale plum #efe7ec. For docs, print, light web pages.
On teal — reversedOn any teal/colored fill the claw goes white. Stickers, merch, action surfaces.

The claw always faces right. The check sits inside the upper-right claw, never outside. Proportions are locked — never stretch or tilt. On a colored background the claw is white.

1.2 Character · C1 (smile-check)

C1 · thin smileTwo eyes, mouth = check. Default character.
C1 · bold smileSame construction, heavier mouth stroke (width 5). For merch, banners — anywhere you want more weight.
C1 · on lightFor light backgrounds: eye whites stay white, pupils and smile go dark plum.

Character is used only at ≥ 48px. Below that — primary mark only (no eyes).

03 Signature accent the headline device

The brand's headline-accent device. The display accent word gets a steep oblique slant in ruby (transform: skewX(-18deg)), with a crisp teal underline bar beneath it (~0.08em tall) that follows the slant. No blur. No glow. The slant + underline is the only sanctioned emphasis on a hero headline. It reads as a tracked, instrument-measured object.

construction

  • · word color = ruby #c75f88
  • · transform: skewX(-18deg), origin left-bottom
  • · underline = teal #3bb0c4 bar, ~0.08em tall
  • · bar follows the slant (skewed with the word)
  • · no filter: blur(), no text-shadow glow

where it lives

Exactly one accent word per headline. Use it on the hero verb or noun that carries the promise — never on a function word, never on more than one phrase per view. Body copy and UI never use the slant; they stay upright.

run agents. safely.

Signature rule. The accent word is the only place the two lead colors touch: ruby word, teal bar. It is the brand's "instrument reading" of a single important word. Keep it sharp — the slant carries the energy, not a glow.

04 Observatory motifs atmosphere & instrument

The brand's atmosphere is a research instrument pointed at deep space. These motifs are part of the brand, not decoration — use them to frame heroes, covers, and dashboards. The mood is precise, quiet, and a little mysterious.

4.1 Deep-field background

obs · deep-field track lock grid · coord

Deep plum base · faint star-field mixing gold and cool glints · low-opacity coordinate grid (masked to fade) · soft radial nebula blooms (warm gold + cool teal). The claw reads as a tracked object with a subtle orbit ring.

HUD frame

Thin corner ticks frame the viewport, with small uppercase mono readouts. Use them to bound a hero or a dashboard panel. The ticks are --teal; readouts are --gold (status) or --teal (live).

Mono, uppercase, letter-spaced. Status segments separated by ·. Signal bars use filled/empty dots; gold for warmth markers, teal for live rails.

Color rules.

1. Ruby #c75f88 is identity-only: the word right and the claw. Don't use it for buttons or links.

2. Teal #3bb0c4 is action/structure: buttons, links, focus, telemetry rails, the signature underline. Gold #cda14b is warmth: eyebrows, ticks, star glints.

3. None of the three lead colors is a semantic state. warn = gold-yellow, err = ruby-red, ok = green, info = teal.

4. Ruby on teal or teal on ruby as large fills — forbidden. On a teal fill, the claw goes white.

5. Minimum text contrast — WCAG AA (4.5:1). Dark text #08151a on teal passes; white check on teal passes.

12 Do / Don't summary

✓ do

Use ruby #c75f88 only for the word right and the mark.
Use teal #3bb0c4 for action: buttons, links, focus, rails, the signature underline.
Use gold #cda14b for warmth: eyebrows, index ticks, star glints.
Accent a hero word with the slant + teal underline (skewX(-18deg)).
Pair Chakra Petch display with Saira body — both squared and angular.
Keep buttons as crisp teal chips — flat fill, small radius, mono label.
In prose use Right Agent (Title Case, two words). Wordmark — lowercase. CLI — rightagent.

✗ don't

Reintroduce orange, "fire," or "coal" — that palette is retired.
Use ruby for buttons or links, or teal/gold for the word "right."
Pair the angular display with a round humanist body (Inter, Nunito, Open Sans).
Blur or glow the accent word — the slant + underline is the only emphasis.
Make buttons rounded, glossy, or glowing.
Write r·igh·t·agent or ri·ght·agent — it breaks the word "right."
Write RIGHTAGENT uppercase or rightAgent camelCase.
Add 🚀 emoji to the tagline or marketing copy.
