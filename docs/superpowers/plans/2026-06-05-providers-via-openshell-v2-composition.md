# Providers via OpenShell v2 Composition — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Route all Right provider network policy through OpenShell v2 profiles + gateway composition; delete Right's own `policy.yaml` endpoint-folding; add an attach + ensure-loaded reliability layer; re-vendor the proto to v0.0.56.

**Architecture:** Every Right provider — built-in-derived (`right-github`) and generic — becomes an OpenShell profile-backed provider attached to the sandbox. The gateway composes each attached profile's endpoints into the effective sandbox policy (Providers v2, `providers_v2_enabled=true`). Right authors/imports profiles (built-in-derived via `derive`, generic via a new `Authored` variant), creates+attaches providers, and after each attach ensures the running sandbox loaded the recomposed policy. `policy.yaml` becomes provider-free (base policy only).

**Tech Stack:** Rust 2024, tonic gRPC (`openshell.v1`), OpenShell CLI v0.0.56, `right-openshell` / `right-codegen` / `right-agent-config` / `bot` / `right` crates.

**Source spec:** `docs/superpowers/specs/2026-06-05-providers-via-openshell-v2-composition-design.md`

**Verification cadence:** targeted package tests after each slice; live `ci_openshell_` gates run explicitly; one final `devenv shell -- cargo test --workspace` before completion. All cargo commands run via `devenv shell -- …`.

**Hard constraint (verified):** every authored profile MUST include a `binaries` allowlist (`'**'` or scoped paths) or the proxy rejects CONNECT regardless of endpoint rules.

fn generic_provider_profiles(
    configs: &[(String, right_agent_config::AgentConfig)],
) -> Vec<right_openshell::managed_profiles::ManagedProfile> {
    let mut out = Vec::new();
    let mut seen = std::collections::HashSet::new();
    for (_agent, cfg) in configs {
        for entry in cfg.providers() {
            if !matches!(entry.type_, right_agent_config::ProviderType::Generic) {
                continue;
            }
            let Some(g) = entry.generic.as_ref() else { continue };
            let id = format!("right-{}", entry.name.trim_start_matches("right-"));
            if !seen.insert(id.clone()) {
                continue; // same provider name across agents → same profile

                &id,

                g.upstream_path_prefix.as_deref(),
                &g.header_name,
                &g.env_var,
            );
            out.push(right_openshell::managed_profiles::ManagedProfile::Authored(Box::new(prof)));
        }
    }
    out
}

/// Poll `probe` every `interval` up to `max_attempts`; true once it returns true.
pub(crate) async fn poll_until_loaded<F, Fut>(
    mut probe: F,
    interval: std::time::Duration,
    max_attempts: u32,
) -> bool
where
    F: FnMut() -> Fut,
    Fut: std::future::Future<Output = bool>,
{
    for _ in 0..max_attempts {
        if probe().await {
            return true;
        }
        tokio::time::sleep(interval).await;
    }
    false
}
